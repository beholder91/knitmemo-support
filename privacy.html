隐私政策

你的编织记录，保存在你的设备里。

更新于 2026 年 10 月 31 日

记录与照片

毛线、项目、计数、日记、照片和 PDF 保存在设备的 App 沙盒中。语言和自定义颜色保存在本机设置中。开发者不收集、接收或出售这些内容。

权限与备份

相机、照片和文件只在你选择添加内容时使用。你可以在系统设置中管理权限，也可以主动导出 ZIP 备份或分享文件。系统备份由你的 Apple 设置管理，导出的副本由你选择的保存位置或服务管理。

保留与删除

记录会保留到你在 App 内删除内容或移除 App。开发者没有服务器副本。导出的备份、原始照片、原始 PDF 和系统备份可在各自的保存位置管理。

网站与反馈

织记没有账号、广告、分析 SDK 或跟踪功能。本网站由 GitHub Pages 托管，GitHub 会出于安全目的记录访问 IP。通过 GitHub Issues 提交的反馈和附件会公开显示，用于处理问题与建议。

联系与更新

数据处理方式变化时，本页会同步更新。隐私问题也可以通过 GitHub Issues 联系开发者。
