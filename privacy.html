隐私政策

更新日期：2026 年 10 月 29 日

数据与收集

织记是一款本地编织日记。开发者不收集、接收或出售 App 内的记录、照片、PDF、身份信息或使用数据。App 不含账号、广告、分析 SDK 或跟踪功能。

本机保存

毛线、项目、计数、日志以及导入的照片和 PDF 保存在 App 沙盒中；语言和自定义颜色保存在本机偏好设置中。App 不自动上传或同步这些内容。设备的系统备份由你和 Apple 的设置管理。

照片与文件权限

只有在你选择拍照、照片或文件时，App 才使用相机或读取你选择的内容，用于保存编织记录。你可在系统设置中管理相机和照片权限。

备份与分享

只有在你主动导出时，App 才生成包含记录、照片和 PDF 的 ZIP 备份。保存或分享位置由你选择，相应服务的隐私规则适用于你交给它们的副本。请妥善保存备份，分享前确认其中的私人内容。

保留与删除

记录保留在本机，直到你在 App 中确认删除或移除 App。App 不保留服务器副本。导出的 ZIP、原始照片、原始 PDF 和系统备份不会随 App 内删除自动移除，请在对应位置自行管理。

支持反馈与本网站

如果你主动通过 GitHub Issues 联系开发者，你的 GitHub 用户名、反馈和附件会按你提交的内容公开显示，开发者仅将这些内容用于处理反馈。不要提交敏感内容；需要修改或删除反馈时，请使用 GitHub 的相应功能或在原反馈中联系开发者。本网站由 GitHub Pages 托管，GitHub 会出于安全目的记录访问者的 IP 地址。访问本网站及使用 GitHub Issues 时，适用 GitHub 隐私声明。本网站不加入广告、分析脚本或跟踪 Cookie。

政策更新与联系

如 App 的数据处理方式变化，本页会同步更新。隐私问题可通过 GitHub Issues 联系开发者。
